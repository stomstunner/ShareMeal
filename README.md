# ShareMeal

ShareMeal connects surplus food with people and communities who need it.

## Stack

- React + Vite frontend
- Express backend
- MongoDB with Mongoose
- Supabase Storage for food images
- Google OAuth and JWT authentication

## Local development

1. Copy `.env.example` to `.env` and add your credentials.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the frontend and backend:

   ```bash
   npm run dev
   ```

The frontend runs on `http://localhost:5173` and the API runs on `http://localhost:5000`.
